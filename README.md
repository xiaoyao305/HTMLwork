# 爪爪日常

一款面向养猫、养狗家庭的中文宠物照护应用。整体风格为**荧光霓虹风**（深色玻璃拟态 + 霓虹青/品红/暖黄点缀），温暖轻松但界面清晰易用。

## Demo

在线演示：**https://xiaoyao305.github.io/HTMLwork/**

（GitHub Pages 部署自 `gh-pages` 分支；数据保存在浏览器 localStorage，打开即用，内置两只示例宠物）

## 核心功能

### 1. 宠物档案与日常管家
- 支持多只宠物：名称、头像、猫狗类型、品种、生日、体重、精力水平
- 记录过敏源、忌口与长期关注事项
- 首页展示今日照护概览：喂食、饮水、遛弯、清洁等日常任务与用药、驱虫、洗护、疫苗、复诊提醒
- 自定义任务内容、频率（每天/每周/每隔 N 天/单次）与提醒时间，完成后打卡，可撤销

### 2. 食物搭配抽签
- 两种模式：
  - **🎲 灵感库推荐**：从内置食物库随机组合 1 主食 + 1–2 辅食 + 0–1 零食，附搭配思路
  - **🏠 家里的食物**：用户维护自家食物清单（名称/角色/适用对象/备注），从现有存货中抽签
- 自动避开宠物档案中的过敏与忌口（自填名称支持同义词扩展匹配，如「乳制品」覆盖奶/酸奶/奶酪）
- 命中危险食物关键词（巧克力、葡萄、洋葱、木糖醇等）的清单条目会示警且不参与抽签
- 支持收藏、换一组、标记「不适合」；附「永远不要喂」清单与免责声明

### 3. 宠物陪玩灵感抽签
- 按猫狗类型、室内/室外、可用时长、宠物精力、现有玩具筛选
- 每条灵感含活动名称、准备物品、操作步骤、建议时长与安全提示
- 支持收藏、换一个、完成打卡并记录宠物反应；条件不满足时逐级放宽并说明

### 4. 记录与提醒
- 打卡历史按日分组、可撤销
- 任务管理：增删改、启停开关
- 重要提醒（用药/驱虫/疫苗/复诊）未来 7 天排期与提醒开关

## 技术栈

- **React 18 + TypeScript + Vite 5**，`react-router-dom`（HashRouter，可静态部署）
- **状态管理**：React Context + `useReducer`，localStorage 持久化（key：`zhuazhua-daily-v1`）
- **样式**：原生 CSS + CSS 变量设计 token，移动优先（390–430px），桌面端居中手机画布
- **动画**：CSS keyframes + 抽签滚动球组件，支持 `prefers-reduced-motion`

## 运行方式

本仓库自带便携版 Node（`.tools/node`），需先设置 PATH：

```bash
export PATH="$(pwd)/.tools/node/bin:$PATH"
npm install      # 首次
npm run dev      # 开发预览 http://localhost:5173
npm run build    # 类型检查 + 构建到 dist/
```

## 目录结构

```
src/
├── store/        # 类型、种子数据、reducer、localStorage 读写
├── data/         # 食物库、危险食物清单、陪玩活动库
├── lib/          # 抽签算法（食物/陪玩）、日期工具、内联 SVG 图标
├── components/   # Toast、Sheet、EmptyState、ProgressRing、DrawOrb 等
├── pages/        # 首页 / 档案 / 食物抽签 / 陪玩抽签 / 记录提醒
└── styles/       # tokens、global、components、pages
```

## 安全边界

所有饮食与健康内容仅为日常灵感，不构成营养或医疗方案；食物以宠物已适应的为前提，特殊病况或不确定食材请先咨询兽医。

## 客户画像

### 核心客户：忙碌的年轻宠物主人

**典型特征**

- 22–35 岁，城市居住，养猫或小型犬
- 工作或学习节奏快，日常安排容易被打断
- 把宠物视为家庭成员，愿意投入时间和预算
- 习惯用手机管理日程、记录生活，也喜欢轻松有趣的互动
- 可能是第一次养宠，正在摸索稳定的照护习惯

**主要痛点**

- 忘记喂食、清洁、驱虫或复诊等安排
- 不确定每天还能为宠物做些什么
- 食物和陪玩方式容易重复，缺少新点子
- 家人共同照护时，容易出现任务遗漏或重复

**使用动机**

希望用一个简单的应用记住照护事项，也能随手获得喂食和陪玩灵感，让宠物生活更规律、更丰富。

**典型使用场景**

早上查看今日任务并确认喂食；下班后抽一个室内陪玩活动；周末记录体重、预约洗护或查看近期照护记录。

---

### 次要客户：多宠家庭的照护协调者

**典型特征**

- 家里养有两只或更多宠物
- 宠物年龄、饮食限制或照护节奏各不相同
- 可能由伴侣、家人或室友共同照看

**主要痛点**

- 不同宠物的任务和饮食要求容易混淆
- 很难确认谁完成了喂食、遛弯或清洁
- 需要查看每只宠物的提醒和历史记录

**产品关注点**

多宠物档案切换、按宠物区分提醒、记录完成情况，以及避免抽签结果忽略个体忌口。

---

### 次要客户：新手养宠者

**典型特征**

- 刚开始养猫或狗，照护经验有限
- 想做好准备，但容易被零散信息弄得不知所措
- 需要的是清晰的日常安排和简单可执行的建议

**产品关注点**

上手简单、提醒容易设置、陪玩建议步骤明确；饮食内容要说明适用条件，遇到特殊健康情况时提示咨询兽医。

**一句话概括：**这是一款面向重视宠物、生活忙碌，又希望照护更有规律和趣味的宠物主人的应用。
